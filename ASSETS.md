# Asset provenance

> **TL;DR:** All demo content is invented. The two images were generated for this project; the silent motion card is original synthetic output. No family media is included.

`docs/assets/family-trip-portal-hero.png` and its identical copy `public/media/trip-illustration.png` are original ChatGPT-generated artwork. `public/media/cedar-bay.png` is an independently generated fictional landscape. Original generated bytes are retained. Prompts are in `docs/IMAGE-PROMPTS.md`. These assets are supplied with the original project's MIT terms to the extent applicable.

`public/media/lantern-loop.webm` is a six-second silent synthetic motion card: a coral square moves over a navy background. It contains no camera footage, recording, voices or external media. `lantern-loop.vtt` describes it. Reproduction command (optional ffmpeg tool, not needed to run the portal):

```sh
ffmpeg -f lavfi -i 'color=c=0x1a3d5c:s=640x360:r=24:d=6' \
  -f lavfi -i 'color=c=0xe07c5a:s=80x80:r=24:d=6' \
  -filter_complex "[0:v][1:v]overlay=x='(W-w)/2+160*sin(t)':y='(H-h)/2'[video]" \
  -map '[video]' -an -c:v libvpx-vp9 -b:v 200k lantern-loop.webm
```

The JSON case and its generator are original fictional examples. The tide wave is a toy cosine function, with no copied measurements or predictions. Emoji are rendered by the visitor's platform; no emoji image collection is bundled.

The two local font files are third-party OFL-1.1 works. Exact upstream URLs, revisions and hashes appear in `third-party/font-provenance.json`; original licenses are beside it. Dependency notices are described in `THIRD_PARTY.md`.
