FAMILY TRIP PORTAL: READY-BUILT FICTIONAL DEMO

Start here: install Node.js LTS (22 or newer) from https://nodejs.org.
Unzip the entire folder. On Mac open Start.command; on Windows open
Start Windows.cmd. Keep its terminal open while using the portal.
If your browser does not open, visit http://127.0.0.1:5050/.
Press Control+C in the terminal to stop.

No npm install, account or internet connection is needed after Node is
installed. All trip content is invented. This is a read-only demo; it
does not save guest edits. A silent synthetic clip demonstrates local video.

To customize, get the source release and follow its README:
https://github.com/jessecmaddox3/family-trip-portal/releases/latest
